# PbCard Widget

## Overview

The `PbCard` widget is a reusable container with a white background, rounded corners, optional border, and responsive padding behavior for desktop and non-desktop layouts. It provides a consistent, customizable card surface across the app.

<img src="https://raw.githubusercontent.com/FocalAgent-Limited/propertybox-ui/main/docs/components/pb_card/image1.png" width="200"/>

## Class Definition

```dart
class PbCard extends StatelessWidget {
  final Widget child;
  final bool border;
  final bool isNarrower;
  final double verticalPadding;
  final double horizontalPadding;

  const PbCard(
      {required this.child,
      this.verticalPadding = 40,
      this.horizontalPadding = 40,
      this.border = true,
      this.isNarrower = false,
      super.key});

  @override
  Widget build(BuildContext context) {
    final isDesktop = DeviceHelper.isDesktop(context);

    return Container(
      decoration: BoxDecoration(
        border: border ? Border.all(color: BrandColors.greyBorderColor, width: 1) : null,
        borderRadius: BorderRadius.circular(20),
        color: Colors.white,
      ),
      padding: isDesktop
          ? EdgeInsets.symmetric(
              horizontal: isNarrower ? 20 : horizontalPadding,
              vertical: isNarrower ? 20 : verticalPadding)
          : EdgeInsets.symmetric(
              horizontal: horizontalPadding == 0 ? 0 : 20,
              vertical: verticalPadding == 0 ? 0 : 20),
      child: child,
    );
  }
}
```

## Properties

- `child` (`Widget`, required): The content displayed inside the card.
- `border` (`bool`, optional, default: `true`): Whether to show a 1px border using `BrandColors.greyBorderColor`.
- `isNarrower` (`bool`, optional, default: `false`): On desktop, forces compact padding (`20` horizontal / `20` vertical), ignoring custom desktop paddings.
- `verticalPadding` (`double`, optional, default: `40`): Desktop vertical padding when `isNarrower` is `false`. On non-desktop, any non-zero value maps to `20`.
- `horizontalPadding` (`double`, optional, default: `40`): Desktop horizontal padding when `isNarrower` is `false`. On non-desktop, any non-zero value maps to `20`.

## Usage

Use `PbCard` in your UI like this:

### Example

Here is an example of how to use the `PbCard` widget in a Flutter application:

```dart
import 'package:flutter/material.dart';
import 'package:propertybox2_app/widgets/pb_card.dart';

class MyHomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text('PbCard Example'),
      ),
      body: Center(
        child: PbCard(
          border: true,
          horizontalPadding: 40,
          verticalPadding: 40,
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              Text(
                'Hello, World!',
                style: TextStyle(fontSize: 20),
              ),
              SizedBox(height: 10),
              Text(
                'This is a custom card widget.',
                style: TextStyle(fontSize: 16),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

### Narrow desktop variant

```dart
PbCard(
  isNarrower: true,
  child: Text('Compact card content'),
)
```

### Edge-to-edge content (mobile + desktop)

```dart
PbCard(
  horizontalPadding: 0,
  verticalPadding: 0,
  border: false,
  child: MyCustomLayout(),
)
```

## Refactor Notes

Current implementation is production-ready and should remain stable for now.

Candidates to evaluate in a later refactor:
- Clarify padding behavior by splitting desktop and mobile paddings explicitly (instead of non-zero mapping to `20` on mobile).
- Review whether `isNarrower` should remain a boolean shortcut or be replaced by a size enum (`compact`, `default`, `spacious`).
- Standardize import/example path so docs snippets are copy-paste ready for the app package.
- Add visual examples for `border: false`, `isNarrower: true`, and zero-padding use cases.
